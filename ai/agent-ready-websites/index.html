The problem

AI assistants are starting to do tasks, not only answer questions: compare prices, check availability, book a slot. An agent that has to guess its way through buttons and forms gives up or gets it wrong. A site that tells the agent exactly what it offers and how to ask gets the booking.

What it does

  • Publishes your services, prices and hours in a format agents read directly.
  • Sets up an MCP server so AI assistants can query your catalog and availability.
  • Adds WebMCP tools to key pages, ready for browsers as they adopt the standard.
  • Decides with you which actions an agent may take and which need a person.

What's included

  • MCP server hosted and monitored, with a log of every request.
  • Up to 5 agent actions, such as "list services", "check availability" or "request a quote".
  • Structured data and machine-readable catalog files.
  • Updates as the standards change. WebMCP is still an early draft.

Questions

Is this technology ready today?

Part of it. MCP servers work today with assistants that support them. WebMCP, the browser side, is still in trial in Chrome and not available to every user. We set up what works now and keep the rest current.

Can an agent charge a card or change my data?

Only if you allow it. By default agents can read and request, and a person approves anything that costs money.

Do I need an AI-ready website first?

Yes. Agents rely on the same clean pages and structured data. If your site needs that work, we do it first.
